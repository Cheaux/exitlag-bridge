# v0.4.1-alpha.1 — Mac Dock and window fixes

This Mac update gives the official ExitLag client its own **ExitLag** Dock
identity and fixes dashboard restoration and window animations.

- The running app is labeled **ExitLag**, with its icon extracted locally from
  the official client you installed. No vendor icon or client is bundled.
- Clicking the ExitLag Dock icon restores the dashboard. The bridge menu also
  has **Show ExitLag dashboard**.
- Minimizing and restoring preserves the window image, without a white frame,
  black dashboard or brief smaller view. A matching Wine display correction is
  installed automatically in the bridge's private runtime.
- The earlier launcher fix for status-file lock contention is included.

For an existing Mac installation, quit **ExitLag Bridge** from its menu-bar
menu, install the new package, then open **ExitLag Bridge** in Applications.
Your existing client, sign-in data and private Wine environment are preserved.
The package refuses to update while the installed bridge is running.
If an older Bridge shortcut remains in the Dock, keep the running **ExitLag**
icon and remove the older duplicate shortcut.

New users still download the official Windows installer themselves and select
it during setup. This bridge does not include ExitLag or a subscription.
See the [setup guide](https://github.com/Cheaux/exitlag-bridge/blob/main/installers/README.md).

## Validation and scope

The Mac bridge's 47 local checks, 13 shared installer checks and five Mac
distribution checks pass. A native AppKit regression check verifies the actual
patched Wine drawing methods, including padded buffers, restore sizing and
temporary-image cleanup. The expanded installer is checked separately for
payload integrity, stock-runtime installation, upgrade behavior and private data.

The maintainer confirmed the Dock name/icon, dashboard restore, animation and
full-size restore on Apple Silicon with macOS 27.2, Wine 11.17 and ExitLag 5.23.3.
This is a window integration update; no new gameplay compatibility is claimed.
The existing [tested-games table](https://github.com/Cheaux/exitlag-bridge#games-tested)
still applies: Mac WoW Classic Era world traffic and Forever character selection;
Arch WoW Classic Era gameplay. Forever world entry and other Mac games remain
unverified. Mac routing remains WoW-specific, IPv4 TCP only.

The Mac app is ad-hoc signed; the installers are **unsigned and not notarized**.
This remains an experimental release. An unrecognized modified Wine driver is
preserved rather than overwritten. Linux binaries are unchanged.
