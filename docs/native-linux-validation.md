# Native Linux validation

Historical packet captures and local network/routing details are deliberately
not included in this repository. See [compatibility](compatibility.md) for the
current supported evidence and [testing](testing.md) for repeatable checks.

Earlier native Linux experiments explored UDP process attribution, TCP/UDP
callbacks, relay selection and cleanup. Recognition of a native game or a short
relay connection did not establish stable gameplay for every tested title.
Those experiments must not be interpreted as a general compatibility claim.

The maintainer has reported successful WoW gameplay on Linux. The release
installer and privileged helper also have account-free Ubuntu CI checks.
Contributors should record actual game results using the compatibility template.
